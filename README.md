# Maths Hub

Interactive student learning hub for Year 12 Mathematical Methods.

Hosted via GitHub Pages and embedded in Canvas via iframe.

## Features
- Weekly lesson accordions with auto-status badges
- Student confidence radar chart
- Flashcard decks per week
- Mood check-in tracker
- Explain-it-back boxes
- AI tutor (Gemini Flash — free)
- Password-locked teacher editor

## Default editor password
`teacher123` — change this immediately via the Edit tab after setup.

## Updating content
1. Go to your repository on GitHub
2. Click `index.html`
3. Click the pencil (edit) icon
4. Make changes in the editor
5. Click "Commit changes"

The live site updates within ~60 seconds.
